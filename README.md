# QSpiders Python Practice

Python exercises from my training at QSpiders. Each file solves one question on conditional statements (`if` / `else`) and user input.

## Exercises

- Check whether a number is even, and print its square if it is
- Check whether a number is even or odd (user input)
- Check whether a number is a multiple of 3
- Check whether a student scored exactly 70%
- Check whether the input is of `list` type
- Find the greater of two numbers (`a = 98`, `b = 67`)

## Running

Requires Python 3.

```bash
python "wap to check the no is odd (take user input).py"
```
